# Gauntlet

A private iPhone app for friend groups. Every Monday an AI drops a fresh list of dares for your group.
You prove them with **live camera** photo or video ("pics or it didn't happen"), your friends swipe to
approve or reject, and accepted proofs earn points, streaks and the weekly crown.

> Working name. Trademark clearance not done yet.

## How it works

- **Weekly dares**: generated by DeepSeek every Monday per group (3–10 dares, optional theme), in the group's timezone.
- **Camera-only proof**: photo or video up to 30 s, no photo-library imports.
- **Voting**: accepted at 2 approvals; rejected when half the group (excluding the submitter) rejects.
- **Points**: easy 10 / medium 25 / hard 50, +10 first finisher, +50 weekly winner, week-streak bonus.
- **Push**: new dares, votes needed, your result, Sunday deadline reminder.

## Run it

**Backend**
```sh
cd backend && npm install
cp .dev.vars.example .dev.vars   # fill in your keys
npx wrangler d1 migrations apply DB --local
npx wrangler dev                 # http://localhost:8787
npx vitest run                   # tests
```

**iOS** (Xcode 26+, `brew install xcodegen`)
```sh
cd ios && xcodegen generate && open Dares.xcodeproj
```
Tap **Try the demo** on the sign-in screen (or launch with `-demo`) to use the whole app offline with sample data.
